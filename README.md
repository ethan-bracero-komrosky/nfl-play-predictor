hi# nfl-play-predictor

During the active NFL season, the dashboard can be connected to nflreadr's nightly feed for next-day game analysis. True real-time prediction would require integration with a commercial play-by-play API such as Sportradar.

- Select any historical game from 2021-2025
- Watch it play out snap by snap at adjustable speed
- Model predicts pass/run probability before each play
- After play resolves, accuracy counter updates
- Team tendency charts update as the game progresses
